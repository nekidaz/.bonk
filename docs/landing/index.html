A FEW PRACTICAL DETAILS

Before you bonk.

Do I need an account or an internet connection?

No account is required. Editing, organizing, and inspecting saved work is local. Sending a request needs access to the target API; update checks and Git remotes also use the network.

Can I move from Postman or cURL?

Yes. Import a Postman Collection v2.x or an OpenAPI / Swagger file, or paste a cURL command into the request URL bar. Bonk also exports Postman collections and OpenAPI specifications. Import support does not imply full Postman compatibility.

Where do my requests and settings live?

Saved requests live in the workspace folder you select. App preferences and session state live separately in the platform application-data directory. Variables marked as secret use the OS keychain when available; keep credentials out of files you commit.

What does the AI integration allow?

You choose whether the MCP server can edit files or call APIs. Read-only mode, disabled network access, and target-host allowlists are available. Bonk supports local STDIO and remote Streamable HTTP connections.

Is the application source in this repository?

This repository contains public releases, documentation, and the website. The application source is maintained separately. See the included license for the terms that apply to distributed material.
